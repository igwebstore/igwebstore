# igwebstore
## public repository for files referenced in "Imitation Games and Turing Tests"
### the top level files include JAVA source code for the distancing tool and a set of BASIC algorithms written by Professor Harry Collins which proved and established the Step1 player/role assignations for each possible number of partipants.
### the imgameapp folder contains source code for the app along with clean database files. The source code and clean database files can be used to host the app on any LAMP stack server.
